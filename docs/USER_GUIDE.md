# 小番茄 1.5.5 使用说明

解压后双击 `小番茄.exe`。单文件下载则运行 `TomoBar.exe`。建议将程序放在固定文件夹。

## 开始专注

直接点击「开始专注」，没有任务时会创建「自由专注」，无需先命名。开始／继续专注后自动收起主窗口，任务栏计时条保留倒计时。

默认专注 25 分钟，短休息 5 分钟，每四轮长休息 15 分钟。完成阶段后等待手动开始下一阶段；不会自动开始下一轮。休息和暂停不计入任务时间。

## 任务栏与小卡片

单击计时条：开始、暂停、继续。双击：直接打开主界面，不改变计时状态。为避免误判双击，单击会按系统双击间隔短暂等待后执行。

休息时，中键单击（按一下滚轮）可直接跳过当前短休息或长休息，暂停中的休息同样适用。跳过后回到待开始状态，再单击左键开始下一轮；专注中或停止时按中键没有作用，滚动滚轮也不会跳过。

红色番茄保持不变。边框和状态点以绿色表示进行中、橙色表示暂停、黑色表示停止。停止时显示「开始」。悬停可查看完整任务名称和当前状态。

右键计时条可以新建便签、打开设置、锁定／解锁位置、恢复位置和退出。菜单打开后，再用左键单击计时条即可收起菜单，这次点击不会顺带暂停或开始计时。解锁后横向拖动可调整位置；设置中的距离填写 `-1` 恢复自动位置。

计时条默认跟随主任务栏。任务栏图标左对齐时放在任务栏上沿；全屏、自动隐藏时暂时隐藏，后台计时继续。当前没有独立副屏选择。

系统托盘图标单击打开小卡片，双击打开主界面。主窗口的 × 只隐藏窗口，退出请使用计时条或托盘右键菜单。

## 富文本便签

主界面进入「便签」，点击「新建便签」。任务栏计时条和托盘的右键菜单也可新建便签；默认快捷键为 Ctrl + Alt + N，在设置中可改为 Ctrl + Alt + M 或关闭。如果快捷键被占用，设置页会提示。

在主界面「便签」列表单击标题即可输入。Enter 或点击别处保存，Esc 取消；标题留空时自动使用正文第一行。标题会同步显示在便签顶部，正文区域不放标题输入框或保存提示。便签独立于计时器，打开、编辑和关闭便签均不会暂停专注。窗口支持调整大小、拖动、最小化和置顶；右键「便签选项」中可选择奶油、鼠尾草和浅玫瑰纸色，也可设置置顶。

便签顶部从左到右显示标题、置顶图钉、最小化与关闭按钮，不再提供最大化按钮。点击图钉使便签始终显示在其他普通窗口上方，再点取消；与右键菜单的「置顶便签」同步。

双击顶部标题栏可折叠为只有标题的小条，再双击展开并恢复原有高度。折叠不会影响正文、完成状态或自动保存，折叠时仍可置顶、最小化和关闭。关闭按钮会保存并关闭当前便签窗口，便签仍保留在主界面；从列表重新打开时展开显示。

拖动顶部标题栏时窗口自由移动；松手时，距离当前屏幕工作区边缘约 12 个逻辑像素以内才会吸附。已贴边的便签可直接向内拖走，慢慢拖动也不会被反复拉回。工作区排除任务栏；展开便签时会调整位置，避免内容落在屏幕外。

输入会在后台自动保存。选中文字后右键，在「文字样式」中选择加粗、斜体、下划线、删除线或高亮；「段落样式」提供正文和大小标题，「列表与缩进」提供分点列表、编号列表及缩进。首层的「待办勾选」是独立开关，也可按 Ctrl+1。Ctrl+B / I / U 对应常用文字格式；Ctrl+Z 撤销，Ctrl+Y 重做。勾选完成后文字变淡并加删除线，留在原位；撤销也支持恢复勾选状态。

编号和待办可组合：选中一行或多行，依次选择「列表与缩进 → 编号列表」与「待办勾选」，顺序不限，显示为 `1. ☐ 待办内容`。分点列表同样支持勾选框。

再次选择「待办勾选」只移除勾选框，保留编号；再次选择已启用的编号列表只移除编号，保留勾选框。多行格式操作保留选区，方便连续设置。混合选择有勾选框和无勾选框的段落时，第一次统一添加，第二次统一移除。

编号待办按 Enter 会生成下一条未完成项，后续编号自动更新；空项再按 Enter 退出列表与待办。Tab / Shift+Tab 调整层级，各层分别编号。段落之间插入普通正文后，新编号列表从 1 开始。完成状态、文字格式与列表结构可以一起撤销或重做。

在新段落输入 `- `、`* ` 可转换为分点列表，输入 `1. ` 转换为编号列表，输入 `[] ` 或 `[ ] ` 转换为待办项。Enter 继续当前列表，空列表项再按 Enter 返回正文。Tab / Shift+Tab 调整缩进。Shift+Enter 在段落内换行。

右键菜单还可插入链接；撤销、重做位于「编辑历史」，清除文字格式位于「文字样式」。未选择文字时剪切和复制会显示为不可用。输入完整 http(s) 网址后加空格会识别链接，Ctrl+单击打开网页。粘贴采用纯文本，便于统一排版，文字样式可通过右键菜单添加；不导入网页脚本、图片或附件。

停止输入约 0.65 秒后自动保存，关闭便签、退出应用时立即保存。任务备份包含便签正文、格式、勾选、颜色和关联信息；未能保存时会提示，保留窗口供重试。

便签页可按标题与正文搜索。删除先移到回收站，可在回收站恢复，不会立即永久删除。便签右键「便签选项」可以关联已有任务，或「转为任务」创建新任务并保留原便签；重复转换已关联便签不会创建重复任务。

## 任务和统计

每个任务可以设置 1–180 分钟的时长和 1–99 个预计番茄。双击任务编辑，名称留空时使用「自由专注」。任务右键菜单支持排序、历史记录和归档。完成／归档保留历史统计。

单击任务卡片只切换右侧时间预览，当前任务继续计时，不会因此保存记录或切换任务。预览其他任务时，右侧显示它的一轮时长；点击「切换并开始」（未计时时为「开始专注」）或任务行的播放按钮才开始该任务。查看正在进行的任务时显示实时剩余时间，可以点击暂停／继续。

同一时刻只计时一个任务。切换任务会保存上一任务的实际专注时间。提前结束保留实际时长，不计为完整番茄。当前任务处于休息阶段时，点击任务的播放按钮会开始新的专注；卡片的继续按钮则继续当前阶段。

时间统计包含今日投入、完整番茄、最近七天趋势、任务累计与专注记录。可导出 UTF-8 CSV，供 Excel 等应用打开。正在进行的计时在结束后进入记录。记录列表显示最近 100 条，导出包含全部历史。

## 设置和开机自启

在「设置 → 启动」开启开机自启，立即生效，默认关闭。登录 Windows 后在后台运行，不弹出主界面，也不会自动开始专注。

自启是当前电脑、当前用户的设置，不随任务备份迁移。移动程序后，在新位置关闭并重新开启自启以更新路径。若已在 Windows「设置 → 应用 → 启动」中禁用，请先在那里重新允许。

其他时长、通知、锁屏与外观设置需要点击「保存设置」。新默认时长用于新任务，不改正在进行的一轮。浅色、深色与跟随系统均可使用。

## 数据、升级和恢复

数据默认保存在 exe 旁边的 `data` 文件夹。如果该目录不可写，使用 `%LOCALAPPDATA%\LittleTomato`。设置页显示实际位置，并提供备份／恢复入口。

运行中的计时约每五秒保存一次，任务更改即时保存。`data.json` 为当前数据，`data.json.bak` 为上一份自动备份。恢复备份前会另存当前数据。

升级前正常退出，只替换程序，保留 `data` 文件夹。重新启动时未结束的计时以暂停状态恢复，离线期间不累计。编号与待办组合便签需要 1.5.2 或更新版本；旧版会拒绝编辑这些便签并保留原始内容，普通旧便签仍可直接升级。睡眠始终暂停，锁屏默认暂停；意外结束进程可能丢失最后约五秒未保存的计时。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 开始／暂停／继续 | Ctrl + Alt + P |
| 打开主界面 | Ctrl + Alt + O |
| 新建任务／便签（根据主界面当前页面） | Ctrl + N |
| 随时新建便签 | Ctrl + Alt + N（可配置） |
| 关闭编辑面板／收起窗口 | Esc |

快捷键被其他应用占用时，可使用计时条、卡片和托盘菜单。

Windows 11 x64，.NET Framework 4.8 或更新版本，无需管理员权限。无账号、无遥测、无网络同步。当前程序没有代码签名或自动更新功能。
