TomoBar · 小番茄的首个 GitHub 正式版本。

### 下载

- `TomoBar-1.4.0-win-x64.zip`：推荐，解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：下载文件校验值。

Windows 11 x64，使用系统自带 .NET Framework 4.8。无需安装、账号或管理员权限。

### 本版优化

统一矢量图标与字体，提高深浅色界面的可读性；小屏幕下可滚动查看完整专注卡片。修复同任务休息切换、实例定位和托盘单双击问题，完善保存失败处理。

保留已确定的任务栏外观与交互：红色番茄、圆角矩形、绿／橙／黑状态、等宽数字；单击开始或暂停，双击查看小卡片。

### 升级与数据

正常退出旧版后替换 exe，保留原 `data` 文件夹。未结束的计时会以暂停状态恢复。开启自启后如果移动了 exe，请在新位置重新关闭、开启自启以更新路径。

应用与下载包均不包含个人数据。当前程序未签名，验证说明及构建方法见仓库文档。
