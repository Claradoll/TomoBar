TomoBar · 小番茄 v1.5.5

修复便签贴边后挪不走的问题。现在拖动过程中自由移动，松手停在屏幕工作区边缘附近才会吸附。已贴边的便签可以直接向内拖离，展开和折叠状态均适用。

新增连续小位移回归，覆盖四个边缘、折叠便签、松手贴边与非移动操作。41 项核心测试和 89 项便签检查通过，共 130 项。

### 下载与升级

- `TomoBar-1.5.5-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

正常退出旧版，只替换程序，保留 `data` 文件夹。原有任务、统计和便签内容均保留。
