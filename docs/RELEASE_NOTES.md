TomoBar · 小番茄 v1.5.0

### 富文本便签

新增独立便签窗口和便签管理页。支持加粗、斜体、下划线、删除线、高亮、标题、分点／编号列表、待办勾选和网页链接，内容自动保存。

完成的待办变淡并加删除线；撤销／重做支持勾选和文字编辑。提供置顶、颜色标记、搜索、回收站恢复、关联任务和转为任务。

从主界面「便签」、任务栏／托盘右键菜单或 Ctrl + Alt + N 开始记录。快捷键可在设置修改或关闭。原有计时与任务栏鼠标操作保留。

### 下载与升级

- `TomoBar-1.5.0-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

升级前正常退出旧版并备份数据，只替换 exe，保留原 `data` 文件夹。旧任务与统计会保留，未结束的计时以暂停状态恢复。便签纳入统一备份；旧版本不认识便签字段，回退旧版本应先额外备份新数据。

本地验证通过 35 项核心测试、57 项番茄钟界面检查和 31 项便签专项检查。Windows 11 x64 / .NET Framework 4.8，无需管理员权限。程序未签名，下载包不含个人任务或便签。
