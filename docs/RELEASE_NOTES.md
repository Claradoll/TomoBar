TomoBar · 小番茄 v1.5.4

- 主界面单击便签标题即可编辑；Enter 或点击别处保存，Esc 取消。便签顶部同步显示标题。
- 顶部加入置顶图钉，保留最小化和关闭，移除最大化按钮。
- 双击顶部折叠为标题小条，再双击展开。折叠后仍可置顶、最小化和关闭。
- 拖动到当前屏幕工作区边缘时自动吸附，展开时调整位置避免超出屏幕。

关闭按钮会保存并关闭当前便签窗口，内容保留在主界面列表。标题留空时自动使用正文第一行。

### 下载与升级

- `TomoBar-1.5.4-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

正常退出旧版，只替换程序，保留 `data` 文件夹。原有任务、统计、标题和便签正文均保留。
