TomoBar · 小番茄 v1.5.2

### 便签右键菜单更清楚

将「文字样式」「段落样式」「列表与缩进」分别归组，常用剪切、复制、粘贴保留在顶部；颜色、置顶、任务关联与回收站集中到「便签选项」，撤销／重做位于「编辑历史」。没有选中文字时，剪切和复制显示为不可用。

### 编号与待办勾选可以一起使用

选中一行或多行，添加编号列表后再开启「待办勾选」，即可得到 `1. ☐ 待办内容`，反过来操作也可以。分点列表同样支持勾选框；Ctrl+1 快速添加或移除勾选框，保留原有编号。

回车继续下一条未完成待办，空项再回车退出。支持多行选区保留、层级缩进、插入自动重编号、撤销／重做和保存恢复。

### 下载与升级

- `TomoBar-1.5.2-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

正常退出旧版，只替换程序，保留 `data` 文件夹。原有任务、统计与便签均保留。组合列表便签需 1.5.2 或更新版本编辑，旧版会保留内容并拒绝打开。
