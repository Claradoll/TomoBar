TomoBar · 小番茄 v1.5.3

便签窗口移除标题输入框与底部「已保存／正在保存」提示，正文空间更简洁。标题只在主界面便签列表显示；已有标题保留，新便签自动使用正文第一行。

后台自动保存、关闭时保存、富文本编辑与编号待办组合继续可用。保存失败时仍会提示，避免未保存内容被关闭。

### 下载与升级

- `TomoBar-1.5.3-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

正常退出旧版，只替换程序，保留 `data` 文件夹。原有任务、统计、标题和便签正文均保留。

本轮通过 38 项核心测试与 60 项便签专项检查，共 98 项，并检查浅色、深色及主界面便签列表。Windows 11 x64 / .NET Framework 4.8。
