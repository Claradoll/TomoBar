TomoBar · 小番茄 v1.5.1

### 更直接的任务栏与任务切换

双击左下角计时条直接打开主界面。右键菜单打开后，再左键单击计时条即可收起，这次点击不会误触开始或暂停。中键跳过休息保持不变。

「我的任务」支持单击预览右侧时长，当前任务继续计时。点击「切换并开始」或任务行的播放按钮才实际切换任务。

### 更像便签的便签

移除常驻编辑工具栏，使用整张纸色背景，只保留标题、正文与保存状态。选中文字后右键设置格式；段落、列表、待办勾选、链接、颜色、置顶和任务关联都在右键菜单中。快捷键、撤销／重做和自动保存保持可用。

### 下载与升级

- `TomoBar-1.5.1-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：文件校验值。

升级前正常退出旧版，只替换程序，保留原 `data` 文件夹。任务、统计与便签内容保留，未结束的计时以暂停状态恢复。
