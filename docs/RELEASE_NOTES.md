TomoBar · 小番茄 v1.4.1

### 中键跳过休息

休息时，对任务栏计时条按一下鼠标滚轮，即可跳过当前短休息或长休息；暂停中的休息也支持。跳过后回到待开始状态，再单击左键开始下一轮，无需打开小卡片。

专注中和停止时中键不触发，滚动滚轮不会跳过。原有左键单击、双击和右键菜单保持原样，任务栏悬停提示会在休息阶段说明新操作。

### 下载与升级

- `TomoBar-1.4.1-win-x64.zip`：解压后运行 `小番茄.exe`。
- `TomoBar.exe`：单文件版。
- `SHA256SUMS.txt`：下载文件校验值。

正常退出旧版后替换 exe，保留原 `data` 文件夹。未结束的计时会以暂停状态恢复。Windows 11 x64，.NET Framework 4.8，无需管理员权限。程序未签名，下载包不含个人数据。
