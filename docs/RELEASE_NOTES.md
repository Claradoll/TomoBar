# TomoBar 1.6.0 · 便签与番茄钟联动

便签右键 **番茄专注 → 编号清单转为任务组**，将一张清单变为可折叠的番茄任务组。标题作为组名、编号作为任务、缩进作为分支；每项独立计时，组内汇总投入和完成进度。

右键清单项即可开始专注，主界面自动收起。文字修改同步任务名称，待办勾选双向同步；新增或调整层级后选择「更新编号任务组」。重复更新保留任务时长和历史，删除清单项保留已生成任务及记录。

默认每项 1 个番茄，时长沿用设置，可单独编辑。完成一轮仍进入休息，下一项由你决定何时开始。

58 项核心测试、126 项便签与 WPF 控件检查通过；浅色和深色界面已渲染核对。测试使用隔离数据；未进行完整人工键鼠或真实多屏兼容性验证。

下载便携 ZIP 解压运行「小番茄.exe」，或直接下载 TomoBar.exe。升级前正常退出，只替换程序，保留 data 文件夹。便签、任务和专注记录保留。
